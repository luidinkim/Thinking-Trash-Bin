# UI 버그 수정 및 편집 기능 디자인

**날짜**: 2026-02-23

## 목표

1. 사이드바가 가려지는 레이아웃 버그 수정
2. 생각 메모 + 본문 내용이 디테일 패널에서 안 보이는 문제 수정
3. 아이템 전체 필드 인라인 편집 기능 추가

## 1. 사이드바 레이아웃 수정

**원인**: 사이드바 `w-56` (224px)이 `Panel defaultSize={15}` (%)와 충돌. 뷰포트 크기에 따라 15%가 224px보다 작아지면 콘텐츠가 잘림.

**수정**: 사이드바를 PanelGroup 밖으로 빼서 고정 너비(w-56)로 배치. PanelGroup은 리스트+디테일 패널만 관리.

```
┌──────┬─────────────────────────────────┐
│Sidebar│  PanelGroup (List + Detail)    │
│ w-56  │  ← 이 부분만 resizable        │
│ fixed │                                │
└──────┴─────────────────────────────────┘
```

- 사이드바: `w-56 shrink-0` 고정, PanelGroup 밖
- 리스트+디테일: PanelGroup 2-panel 구조 유지

## 2. 본문 콘텐츠 표시 수정

**원인**: `buildMarkdownBody()`가 `thinkingNotes`를 렌더링하지 않음. 모든 필드가 비어있으면 빈 화면.

**수정**:
- `buildMarkdownBody()`에 `thinkingNotes` 섹션 포함
- 빈 콘텐츠일 때 "내용이 없습니다" placeholder 표시
- 생각 노트는 본문 섹션 아래 구분선 후 표시

## 3. 인라인 편집 기능

**동작**:
1. 디테일 패널 액션바에 "편집" 버튼 추가
2. 클릭 시 디테일 패널이 편집 모드로 전환 (같은 위치)
3. 편집 가능 필드: 제목, 우선순위, 태그, 문제상황, 현재구조, 개선아이디어, 영향범위
4. 생각 노트: 읽기 전용 (세션으로만 작성)
5. "저장" → updateItemContent() → GitHub 커밋 → 뷰 모드 복귀
6. "취소" → 변경 사항이 있으면 확인 다이얼로그 → 뷰 모드 복귀

**편집 모드 UI**:
- 제목: input
- 우선순위: S/A/B 토글 버튼
- 태그: chip + 삭제(x) + 새 태그 입력
- 본문 4섹션: 각각 textarea (auto-resize)
- 생각 노트: 읽기 전용 마크다운 렌더
- 하단: [취소] [저장] 버튼
